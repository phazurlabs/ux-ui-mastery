Seven phases. Thirty steps. Each command suggests the next.

```
GROUND       /01-ground  →  /02-brief                                        know your problem

BUILD        /17-tokens  →  /18-screen  →  /19-ship  →  /20-generate  →  /21-assets    ship your product
```

Start anywhere. `/guide` shows you where you are and what comes next. `/next` auto-advances. `/status` shows your progress dashboard.

New to UX? Start at `/01-ground`. It takes 60 seconds. Already experienced? Jump to `/04-taste` or `/19-ship`.

## Getting best results

The golden rule: **give context, get precision.**

Every command works better when it knows *what* you're building, *who* it's for, and *what platform* it targets.

```
# Generic — Sumi guesses
/19-ship button

# Precise — Sumi tailors every decision
/19-ship button for a fintech iOS app, primary CTA for wire transfers,
must support Face ID confirmation, audience is 35-55 professionals
```

The second prompt gives Sumi enough to select trust-first color psychology, clinical motion, formal tone, generous touch targets, and iOS HIG conventions.

<details>
<summary><strong>Six prompting patterns</strong></summary>

**1. State your platform.** Sumi generates React/TypeScript, SwiftUI, and CSS. Default is React. Be explicit.

```
/19-ship toggle — SwiftUI with ViewModifiers
/19-ship dialog — vanilla CSS, popover API, no framework
```

**2. Name your tokens.** If you have a design system, tell Sumi so output integrates.

```
/19-ship card — tokens: --color-surface-primary, --space-md (16px),
--radius-lg (12px). Font: Inter. 4px grid.
```

**3. Specify your audience.** Audience changes touch targets, font sizes, contrast, density, and reading level.

```
/18-screen settings for users aged 65+
/18-screen dashboard for developers, keyboard-first
```

**4. Declare accessibility level.** Default is WCAG 2.2 AA.

```
/14-access — evaluate against WCAG 2.2 AAA
/13-think — prioritize cognitive load for users with ADHD
```

**5. Chain context.** Reference output from previous commands.

```
I ran /04-taste fintech and got Inter + DM Sans, blue-600 (#2563EB),
8px grid, medium radius. Now /19-ship button using that direction.
```

**6. Control depth.** Narrow or widen the output.

```
/12-audit — only severity 3 and 4
/23-roast — every dimension, code fixes for every finding
/13-think — focus on cognitive load in the form only
```

</details>

## Install

### Marketplace (recommended)

```
/plugin marketplace add phazurlabs/sumi
/plugin install sumi@sumi-marketplace
```

Done. Works in every session.

### Manual

```bash
mkdir -p ~/.claude/plugins && cd ~/.claude/plugins
git clone https://github.com/phazurlabs/sumi.git
```

Add to `~/.claude/settings.json`:

```json
{
  "enabledPlugins": {
    "sumi": true
  }
}
```

### Verify

Restart Claude Code and run:

```
/04-taste saas
```

Commands appear as `/sumi:command-name`. Skills activate automatically — ask about any UX topic.

<details>
<summary><strong>Troubleshooting</strong></summary>

| Problem | Fix |
|---------|-----|
| Commands not showing | Restart Claude Code |
| `/plugin` not recognized | Update Claude Code to latest |
| Skills not activating | Check `.claude-plugin/plugin.json` exists |
| Uninstall | `/plugin uninstall sumi` or remove from `settings.json` |

Pure markdown. Zero dependencies. Works offline.
