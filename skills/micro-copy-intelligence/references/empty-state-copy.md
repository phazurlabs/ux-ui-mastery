# Empty State Copy Templates

> 150+ production-ready empty state copy templates organized by type and component. Every template includes headline, body text, CTA, illustration suggestion, and tone variants.

## Empty State Anatomy

Every empty state should have:

```
[Illustration/Icon]     — Visual that matches the mood (not required, but recommended)
[Headline]              — What the user sees (brief, specific)
[Body text]             — Why it's empty + what to do (1-2 sentences)
[Primary CTA]           — The action that fills the empty state
[Secondary CTA]         — Optional: learn more, import data, skip
```

**Rules:**
- Empty states are opportunities, not dead ends
- Always provide a path forward (CTA)
- Match the tone to the reason: encouraging for first-use, helpful for no-results, calm for errors
- Keep body text under 2 sentences
- Illustration should be lightweight, not a distraction

## 9. Empty State Illustration Guide

| Mood | Style | Colors | Examples |
|------|-------|--------|---------|
| **Encouraging** | Upward motion, growth, opening | Warm brand colors, green accents | Plant sprouting, sunrise, door opening |
| **Calm/Neutral** | Static, centered, balanced | Muted brand colors, soft grays | Empty desk, blank page, quiet landscape |
| **Achievement** | Celebratory, completed | Gold, green, brand primary | Trophy, checkmark, confetti |
| **Error/Problem** | Broken, disconnected | Muted red/orange, grays | Broken chain, unplugged cable, cloudy sky |
| **Search** | Looking, exploring | Blue, brand colors | Magnifying glass, telescope, binoculars |
| **Locked/Gated** | Barrier, protection | Gray, muted brand | Lock, shield, keyhole |

**Rules:**
- Illustrations should be brand-consistent (match your design system)
- Max 200x200px for empty state illustrations
- Use SVG for crisp rendering at all sizes
- Include `alt=""` (decorative) or meaningful alt text if the illustration conveys information
- Never use illustrations that depict people in a way that could feel exclusionary
- Prefer abstract or object-based illustrations over illustrations of specific people

## 10. Empty State Accessibility

- Empty state messages must be in the DOM, not just visual (screen readers must be able to read them)
- If content is expected to load, announce "Loading..." via `aria-live="polite"` first, then announce the empty state
- CTA buttons within empty states must be keyboard-accessible
- If the empty state replaces a list or table, use `aria-label` on the region: `aria-label="Projects list, empty"`
- Color must not be the only indicator — pair icons with text
- For dynamic empty states (filtering results to zero), announce the change: "0 results found" via `aria-live="polite"`
