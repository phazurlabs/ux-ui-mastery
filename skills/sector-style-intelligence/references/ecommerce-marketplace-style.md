# E-Commerce & Marketplace — Sector Style Intelligence

## Sector Overview

E-commerce and marketplace design exists at the intersection of brand expression and conversion optimization. Unlike SaaS tools (where the UI is the product) or social media (where user content is the product), e-commerce interfaces serve as a stage for physical or digital goods. The design must simultaneously: showcase products with maximum visual impact, build trust for financial transactions, reduce friction to purchase, and communicate brand positioning (luxury vs. value, boutique vs. mass-market, curated vs. comprehensive).

The sector splits into several distinct archetypes: **Direct-to-consumer** (Shopify storefronts, Nike, Glossier) where brand expression dominates; **Marketplaces** (Airbnb, Etsy, DoorDash) where trust between strangers is the core design challenge; **Luxury commerce** (SSENSE, Mr Porter, Net-a-Porter) where restraint and editorial design signal premium positioning; and **Resale/Authentication** (StockX, The RealReal, GOAT) where verification and authenticity are the primary trust mechanisms. Each archetype has distinct visual conventions.

## Color Psychology

### What Colors Mean in E-Commerce

| Color | Association | Usage | Notes |
|---|---|---|---|
| **White** | Premium, clean, gallery | Product showcase backgrounds | White space = luxury signal |
| **Black** | Premium, authority, sophistication | Luxury brands, CTAs on premium sites | Black CTA buttons signal premium intent |
| **Red/Orange** | Urgency, sale, action | Sales badges, limited-time offers, CTAs | The universal "buy now" color — use responsibly |
| **Green** | Trust, verification, go | Add to cart, verified badges, success | "Add to bag" often uses green |
| **Yellow** | Attention, value, deals | Deal highlights, star ratings | Amazon-coded — signals value shopping |
| **Blue** | Trust, reliability | Trust badges, payment security, links | PayPal blue, Venmo, payment-adjacent |
| **Gold** | Premium, membership, exclusivity | Premium tiers, membership badges | Premium/gold card membership |
| **Neutral Beige/Cream** | Organic, artisanal, handmade | Etsy-coded, craft marketplace aesthetic | Signals handmade/independent |

## Typography Norms

### Font Choices Across Leading E-Commerce Apps

| App | Primary Font | Why |
|---|---|---|
| **Shopify Dawn** | Assistant (variable), system | Clean, flexible, weight-variable for hierarchy |
| **Airbnb** | Cereal (custom), system | Geometric, friendly, distinctive brand font |
| **Nike** | Nike Futura (custom), Helvetica Neue | Bold, athletic, iconic — Futura communicates forward motion |
| **StockX** | Inter, Aktiv Grotesk | Clean, financial-feeling, data-readable |
| **Etsy** | Guardian Egyptian (serif), system | Serif communicates craft, editorial, heritage |
| **DoorDash** | TT Norms Pro, system | Friendly geometric sans, clean at small sizes |
| **SSENSE** | Suisse Intl, custom | Swiss modernist — luxury through restraint |
| **Mr Porter** | Mr Eaves (custom), serif | Editorial serif — magazine sophistication |
| **Net-a-Porter** | System, serif for editorial | Fashion-magazine inspired type hierarchy |

### E-Commerce Typography Rules

1. **Product names are sacred.** Product titles should be 16-18px, 500-600 weight. Never truncate product names — they carry search and brand value.

2. **Prices are the most important number.** Current price: 18-24px, 700 weight. Original (crossed-out) price: same size, 400 weight, muted color with `text-decoration: line-through`.

3. **Ratings must be instantly scannable.** Star rating + review count: 13-14px, inline with star icons.

4. **Luxury demands restraint.** Luxury e-commerce uses fewer sizes, lighter weights, and more letter-spacing. Uppercase at small sizes is a luxury convention.

```
Product Grid:
  Product Name:     16px / 500 weight / 1.3 line-height
  Brand Name:       13px / 400 weight / 0.04em tracking / uppercase (luxury)
  Price:            16px / 600 weight / tabular-nums
  Sale Price:       16px / 600 weight / color: red
  Original Price:   14px / 400 weight / line-through / muted
  Rating:           13px / 400 weight

Product Detail:
  Product Name:     28px / 600 weight / -0.01em tracking
  Brand Name:       14px / 500 weight / 0.06em tracking / uppercase
  Price:            24px / 700 weight
  Description:      16px / 400 weight / 1.6 line-height
  Spec Label:       13px / 600 weight / uppercase
  Spec Value:       14px / 400 weight

Marketplace:
  Listing Title:    16px / 600 weight
  Host/Seller:      14px / 400 weight
  Price:            16px / 600 weight
  Per Night/Unit:   14px / 400 weight / muted
  Location:         14px / 400 weight / muted
```

## Component Conventions

### Border Radius

E-commerce uses moderate radii — friendly enough to feel approachable, structured enough to feel trustworthy.

```
Product Card:        12px  (soft, browsable)
Product Image:       8-12px (slight softening, not harsh)
Buttons:             8px  (standard) or 24px (pill for "Add to Bag")
Input Fields:        8px
Size Selectors:      4-8px (compact, grid-based)
Color Swatches:      50% (circular)
Rating Stars:        N/A (icon-based)
Cart Badge:          50% (circular count badge)
Chips/Filters:       20px (pill-shaped for browsability)
Modal/Bottom Sheet:  16px top corners
Thumbnails:          8px
Avatar (Seller):     50%
Trust Badges:        4px (compact, official)
```

#### Luxury Exception
```
Product Card:        0px  (sharp corners — gallery/museum aesthetic)
Product Image:       0px  (no rounding — editorial)
Buttons:             0px  (sharp — premium signal)
```

## Spacing Philosophy

E-commerce spacing is contextual: product grids need density for browsing, product detail pages need breathing room for decision-making, and checkout flows need focused whitespace to reduce abandonment.

### Spacing Scale

```
4px   — Micro (badge padding, icon gaps)
8px   — Tight (product card internal, grid gaps mobile)
12px  — Default (card padding, inline spacing)
16px  — Standard (section gaps, grid gaps desktop)
20px  — Comfortable (product detail sections)
24px  — Spacious (between content blocks)
32px  — Section (major content divisions)
48px  — Page section (hero to content gap)
64px  — Major page (between major sections on desktop)
80px  — Luxury spacing (generous whitespace for premium positioning)
```

### Grid Systems

```
Product Grid (Mobile):
  Columns: 2
  Gap: 8px
  Card padding: 0 (full-bleed images)
  Side margin: 16px

Product Grid (Tablet):
  Columns: 3
  Gap: 16px
  Side margin: 24px

Product Grid (Desktop):
  Columns: 4-5
  Gap: 16px-24px
  Side margin: 32-48px
  Max-width: 1440px

Marketplace Grid:
  Columns: 2 (mobile) / 3 (tablet) / 4 (desktop) / 6 (wide)
  Gap: 24px
  Max-width: 1760px (Airbnb uses wide grids)

Luxury Grid:
  Columns: 2-3 (never more — fewer items = more exclusive feel)
  Gap: 24-40px
  Max-width: 1200px
```

### Checkout Spacing

```
Form field height:    48px
Field gap:            16px
Section gap:          32px
CTA height:           52px
Page max-width:       560px (narrow — focused)
Side padding:         24px (mobile) / 48px (desktop)
Order summary width:  360px (desktop sidebar)
```

## Motion Personality

E-commerce motion serves two masters: showcasing products (smooth, appreciative) and facilitating purchase (fast, confirming).

### Timing

```
Product image hover:     300ms (subtle zoom — appreciation)
Add to cart confirmation: 400ms (satisfying — reward the action)
Cart badge increment:    250ms (bounce scale — visible feedback)
Image carousel swipe:    300ms (smooth slide)
Quick view open:         250ms (fast — don't slow browsing)
Filter application:      200ms (content re-layout)
Checkout step transition: 300ms (smooth but not slow)
Price counter animation:  400ms (dynamic pricing, countdown)
Wishlist heart:          300ms (fill + scale)
Page skeleton load:      Shimmer at 1.5s cycle
```

### Easing Curves

```css
/* Product appreciation — image zoom, gallery scroll */
transition-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1.0);

/* Action confirmation — add to cart, wishlist */
transition-timing-function: cubic-bezier(0.34, 1.56, 0.64, 1.0);

/* Quick interaction — filter, sort, close */
transition-timing-function: cubic-bezier(0.4, 0.0, 0.2, 1.0);

/* Content re-layout — grid reorganization */
transition-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1.0);
```

### Specific Patterns

- **Image gallery:** Horizontal swipe with momentum, snaps to image boundaries at 300ms. Dot indicator follows with slight delay (50ms).
- **Add to cart:** Button text changes "Add to Bag" -> checkmark icon, 200ms. Simultaneously, cart icon badge increments with 250ms bounce (scale 1.0 -> 1.3 -> 1.0).
- **Wishlist heart:** Outline heart fills with red, 200ms. Subtle scale pulse (1.0 -> 1.2 -> 1.0) with 300ms spring.
- **Quick view modal:** Slides up from bottom (mobile) or scales in from center (desktop), 250ms with decelerate easing.
- **Filter sidebar:** Slides in from left, 250ms. Products re-lay with 200ms stagger animation.
- **Skeleton loading:** Content placeholder with shimmer gradient (left-to-right sweep, 1.5s cycle, infinite until loaded).
- **Price drop animation:** Old price fades + slides up, new price fades + slides down, total 400ms.

## Trust Signals

### E-Commerce Trust Elements

1. **Secure checkout indicators.** Lock icon + "Secure Checkout" near payment form. SSL badge. Payment method logos (Visa, Mastercard, PayPal, Apple Pay, Google Pay).
2. **Review system.** Star ratings with review count ("4.8 (2,347 reviews)"). Verified purchase badges. Photo reviews.
3. **Return policy visibility.** "Free Returns within 30 days" prominently displayed on product pages and checkout.
4. **Shipping transparency.** Estimated delivery date, shipping cost (or "Free Shipping"), tracking availability.
5. **Seller verification (marketplace).** Identity verified badge, response rate, response time, member since date.
6. **Authentication (resale).** "Verified Authentic" badge, authentication process explanation, money-back guarantee.
7. **Social proof.** "1,234 people bought this today," "Selling fast," "98% of buyers recommend." Use honestly.
8. **Contact accessibility.** Live chat widget, phone number, email — visible customer support signals reduce purchase anxiety.
9. **Professional photography.** High-quality product images from multiple angles, on model/in context, with zoom capability. Poor photography is the #1 trust destroyer in e-commerce.
10. **Consistent branding.** Matching visual language across product page, cart, checkout, and confirmation email signals a professional operation.

### Marketplace-Specific Trust

1. **Host/Seller profile completeness.** Photo, bio, response rate, verification badges, reviews.
2. **Two-sided reviews.** Both buyer and seller review each other — accountability.
3. **Dispute resolution visibility.** "Money-back guarantee" or "AirCover" style protection programs.
4. **Platform transaction guarantees.** "Never pay outside the platform" messaging.
5. **Insurance/protection badges.** Host Protection Insurance, buyer protection.

### Anti-Patterns — E-Commerce

1. **Fake urgency.** "Only 2 left!" when the counter never actually reaches zero. "Sale ends in 2:00:00" that resets on page refresh. Users recognize and distrust these patterns.
2. **Hidden costs until checkout.** Shipping fees, taxes, and handling charges appearing at the final checkout step cause cart abandonment. Show total cost early.
3. **Forced account creation.** Requiring account creation before checkout adds friction. Offer guest checkout with optional account creation after purchase.
4. **Dark pattern subscriptions.** Pre-checked "Subscribe and Save" options, difficult-to-cancel subscriptions. Increasingly regulated and brand-damaging.
5. **Low-quality product images.** Single image, small size, no zoom, white-box-only. Customers need multiple angles, context shots, and zoom capability.
6. **Cluttered product pages.** Showing 20 cross-sell recommendations, 5 banners, and 3 pop-ups on a product page creates decision paralysis and erodes trust.
7. **Fake reviews.** Generic five-star reviews without detail or with AI-generated text. Customers can spot these and they destroy credibility.
8. **Manipulative countdown timers.** Aggressive countdown timers on non-limited items. Ethical alternative: real-time inventory indicators with honest availability.
9. **Complex return processes.** Requiring customer service calls, restocking fees, or complex forms for returns. Friction in returns creates friction in purchasing.
10. **Newsletter popup on first visit.** A full-screen "Sign up for 10% off" popup before the user has seen a single product is the most despised pattern in e-commerce.

## Reference Apps — What to Learn from Each

### Shopify
- **Lesson:** The design system as a platform. Study Shopify's Polaris design system — it powers both the merchant admin dashboard and provides guidelines for storefronts. Learn how one design system serves both B2B (merchant) and B2C (shopper) contexts.
- **Key pattern:** Merchant admin with left sidebar navigation, product card grid with bulk actions, analytics dashboard with key metrics, theme editor with real-time preview.
- **Polaris tokens:** Shopify's open-source design system provides production-ready tokens for commerce applications.

### Airbnb
- **Lesson:** Search-to-book as a masterclass in progressive disclosure. Study how Airbnb reveals information progressively: search results show the minimum (photo, price, rating, location) while the listing page reveals everything needed for a booking decision.
- **Key pattern:** Map + list split view, photo carousel with dots, price breakdown transparency, review system with category ratings, Superhost and Guest Favorite badges.
- **Photography:** Airbnb's photo guidelines for hosts demonstrate how photography standards create platform-wide trust.

### Nike SNKRS
- **Lesson:** Scarcity and exclusivity as design language. Study how SNKRS creates anticipation through "upcoming" launches, draw mechanics, and sold-out states. The UX of limited drops is a specialized design challenge.
- **Key pattern:** Feed-style product discovery, drop countdown timers, draw entry flow, sold-out states, size selection grid, "Got 'Em" celebration screen.
- **Brand identity:** Nike proves that strong brand identity can coexist with conversion-optimized e-commerce. The brand enhances rather than hinders the shopping experience.

### StockX
- **Lesson:** Financial market UX applied to commerce. Study how StockX borrows stock market conventions (bid/ask spread, price history charts, ticker-style price movements) to position resale as a legitimate market.
- **Key pattern:** Bid/ask price display, price history chart (12-month), size-specific pricing grid, authentication status flow (pending -> authenticated -> shipped), portfolio view for sellers.
- **Trust mechanism:** The verification process (buyer purchases -> StockX receives -> authenticates -> ships to buyer) is a design feature, not just logistics.

### Etsy
- **Lesson:** Connecting buyers with makers through warm, human design. Study how Etsy differentiates from Amazon through warmth — seller stories, handmade emphasis, and editorial curation.
- **Key pattern:** Shop sections with seller branding, custom/personalization options on product pages, Star Seller badge system, gift-wrapping options, estimated delivery with handmade processing time.
- **Marketplace challenge:** Balancing seller customization (each shop has its own personality) with platform consistency.

### DoorDash
- **Lesson:** Real-time operations UX — designing for delivery logistics. Study how DoorDash manages the complexity of three-sided marketplace (customer, restaurant, dasher) through clean, status-focused design.
- **Key pattern:** Restaurant card with delivery time/fee/rating, menu categories with sticky nav, cart drawer, real-time order tracking map, driver location tracking, ETA updates.
- **Time as design:** DoorDash's most critical metric (delivery time) is the most prominent element on every screen — restaurant cards, cart, tracking. Time-prominence is a core design principle.

## Quick Decision Framework — E-Commerce

1. **Is this a brand store or a marketplace?** Brand: invest in brand expression, editorial design, storytelling. Marketplace: invest in trust mechanics, seller profiles, reviews.

2. **What price point?** Under $50: optimize for speed, minimize friction, social proof. $50-500: balance information and aspiration. Over $500: luxury aesthetic, detailed product information, premium trust signals.

3. **Is this a considered purchase or impulse?** Considered (furniture, electronics): detailed specs, comparison tools, reviews. Impulse (snacks, accessories): fast add-to-cart, minimal friction, social proof.

4. **Single product or catalog browse?** Single hero product: editorial product page, storytelling, hero imagery. Large catalog: robust filtering, grid efficiency, search quality.

5. **What is the competitive differentiator?** Price: prominently display savings, deals, comparisons. Quality: premium photography, materials detail, craftsmanship story. Speed: delivery time as the hero metric. Curation: editorial voice, expert picks, themed collections.

6. **Is this a repeat-purchase product?** If yes: optimize reorder flow (one-tap reorder), subscription options, past order access. If no: focus on discovery and first-purchase conversion.
